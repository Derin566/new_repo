Research & Technical Project Report

Dyslexia Monitoring System

Multimodal Cognitive Screening, Gameplay Telemetry & Automated Feature Extraction

1. Executive Summary & Problem Statement

Dyslexia is a neurodevelopmental learning condition primarily characterized by difficulties with accurate and/or fluent word recognition, decoding, and phonological processing. It impacts approximately 10–15% of the global school-aged population.

Core Motivation: Traditional psychometric tests require certified psychologists, expensive equipment, and are often administered only after a child has repeatedly failed in reading. Our solution provides an accessible, language-independent, game-based cognitive screening tool for ages 5 to 14, extracting sub-millisecond behavioral and acoustic features directly into a cloud database.

2. Scientific & Theoretical Grounding

The architecture and mechanics of this system are strictly grounded in peer-reviewed neuropsychological research:

  • Primary Base Study: "Screening Dyslexia Using Visual Auditory Computer Games and Machine Learning" (IEEE Access, Vol. 13, 2025) by Maria Rauschenberger, Ricardo Baeza-Yates, and Luz Rello. Proved that language-independent visual and auditory gameplay metrics predict dyslexia with high accuracy across languages.
  • Visual Magnocellular & Mirror Confusion Theory (Stein & Walsh): Explains the neurological difficulty dyslexic individuals experience with horizontal/vertical mirror inversions (e.g., $b/d$ and $p/q$ confusion).
  • Auditory Temporal Sampling & Rise-Time Theory (Dr. Usha Goswami, Cambridge): Impaired perception of acoustic rise-time (envelope attack speed) directly impairs rhythmic alignment and speech syllable perception.
  • Working Memory Capacity Norms (Gathercole et al., 2004): Calibrates sequence spans strictly across developmental stages: 2–3 items for ages 5–7; 3–4 items for ages 8–10; 4–5+ items for ages 11–14.
  • Non-Word Repetition Task (NWRT) (Gathercole & Baddeley): Isolates pure phonological memory from vocabulary bias using clinical pseudo-words (e.g., "Ba-Lo-Ka").

3. The 6 Multimodal Cognitive Games

1. 🔍 Visual Search (Target Hunt)

A Whac-A-Mole style grid ($2\times2$ to $3\times3$) where children locate a target glyph amidst visually similar distractors. Evaluates visual processing speed and attentional span.

2. 🪞 Symmetry & Mirror Detection

Presents dual geometric vector shapes. The child determines whether they are identical twins or mirror flips ($180^\circ$ or $90^\circ$). Directly detects mirror confusion errors.

3. 🧠 Visual Memory (Corsi Block)

Tiles illuminate in sequence with synchronized musical chords (Do-Re-Mi). The child repeats the sequence. Progress dots track input steps.

4. 🧩 Pattern & Texture Match

Raven's progressive matrix style puzzle with missing texture sequences (chevron waves, polka dots, stripes, concentric rings). Evaluates rapid visual closure.

5. 🎵 Auditory Memory & Rhythm

Web Audio API synthesizes melodic chords across distinct acoustic frequencies (659Hz, 440Hz, 261Hz). The child taps a drum in sync with the beat.

6. 🎙️ Voice Speech Task (NWRT)

Mascot prompts an age-calibrated clinical pseudoword (e.g. "Ba-Lo-Ka"). The child speaks into the microphone while an animated waveform records acoustic timing.

5. Technical Architecture & Infrastructure

  • Frontend: React 19 + Vite 6 + Tailwind CSS 3.
  • Dyslexia Typography: Google Font Lexend (scientifically proven to decrease visual crowding and stress).
  • Audio Engine: Native Web Audio API synthesizer (pure sine/triangle oscillator waves, zero audio file downloads required).
  • Cloud Database: Google Cloud Firestore (NoSQL document database, live project dyslexiamonitering).
  • Authentication: Firebase Auth with New User vs. Returning User state detection.
  • Admin & Calibration Portal: Passcode-protected researcher hub (passcode admin123) to control rounds ($1, 3, 5, 10$), timers, and download CSV datasets.
